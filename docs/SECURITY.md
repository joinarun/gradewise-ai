# Security and privacy

Data stays in the teacher's browser or mobile workspace by default. Cloud requests for grading require explicit consent. Never put student identifiers into model prompts. Redact names and identifying details from answer text before any transmission. The Spark project and demonstration materials are intended for synthetic or non-sensitive data because Gemini Developer API unpaid data terms apply.

Treat all uploads and model output as untrusted data. Prompt inputs are bounded and quoted, returned content is validated, interface rendering uses plain text, and spreadsheet exports escape formula prefixes. No private credentials, debug tokens or real student records belong in Git.

Firebase config identifiers route requests. App Check establishes app attestation; Firebase Authentication establishes user identity; Firestore rules authorize document access. The current local workspace does not sync or require an account. The included Firestore rules deny all access.
